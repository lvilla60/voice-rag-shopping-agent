# Data availability and publication rights

The proposed repository contains the application source, tests, clean notebooks, scientific figures and derived aggregates. Original data and results remain in the working copy outside the publication set.

| Locally retained path | Contents | Reproduction route |
|---|---|---|
| `data/manifest.json` | Preparation settings, counts and content fingerprints | Regenerated by notebook 01. |
| `data/processed/` and `data/eval/` | ESCI-derived catalog, queries and relevance judgments | Obtain the upstream Spanish ESCI data through the project preparation workflow. |
| `data/index/` | Embeddings and retrieval evaluation artifacts | Regenerate caches and retrieval evaluation using notebook 03. |
| `data/scenarios/` | Model summaries and detailed conversations | Regenerate for the same scenario definitions with notebook 05. |
| `data/voz/` | Reference voice and recorded user turns | Supply a reference recording and scenario recordings that you have permission to use. |
| `data/voz_resultados_colab/`, `data/voz_resultados/` and `data/prueba_colab/` | Audio, traces and metrics from official and development runs | Generate new local results using notebooks 06 and 00. |
| `lab4_solution/notebooks/` and `documentos/` | Original notebooks with outputs and academic materials | The public copies and documentation describe the method. |

The benchmark is Amazon's Shopping Queries Dataset (ESCI). The source code names the upstream examples and products Parquet files under the Amazon Science `esci-data` distribution. Notebook 01 can acquire them and construct the Spanish reduced subset. The proposed repository excludes upstream data files, derived catalog rows and labels, indexes, and stock databases. The included aggregate tables are reported measurements.

## Checkpoint and software terms

| Component | Local attribution and licensing status |
|---|---|
| Amazon ESCI | Amazon Science, Shopping Queries Dataset. The local project identifies its distribution but does not include the applicable upstream data license text. |
| Whisper | OpenAI Whisper large-v3-turbo, via CTranslate2 and `faster-whisper` in Colab. Check the original checkpoint and runtime terms before reuse or redistribution. |
| E5 and BGE | `intfloat/multilingual-e5-base` and `BAAI/bge-reranker-v2-m3`. The local project records checkpoint identifiers. No checkpoint license texts were found in the local project. |
| Qwen models | `Qwen2.5-7B-Instruct`, `Qwen3-8B` and `Qwen3.5-9B` from Qwen. Exact upstream distributions are listed in the architecture guide. The local project does not establish model or variant redistribution rights. |
| XTTS-v2 | The project documents Coqui Public Model License (CPML) terms and non-commercial academic use. Consult the applicable terms for the exact checkpoint before running or redistributing it. The implementation sets Coqui's terms-acknowledgment environment variable. |
| ECAPA-TDNN | SpeechBrain model `speechbrain/spkrec-ecapa-voxceleb`, with an ECAPA-TDNN architecture trained on VoxCeleb. The project does not include an applicable checkpoint license text. |
| Other dependencies | The lockfile records package versions, distribution URLs and hashes. Dependency terms remain those of their upstream distributions. |

No model weights, third-party dependency binaries or voices are included. The local project did not contain an applicable public software license for the team's source. A repository license and publishing authority remain decisions for the Group 8 contributors.

Exact reproduction of the original voice experiment requires the original speech recordings and runtime context. A new authorized recording and newly recorded prompts support replication of the method with a different sample. [Reproduction guide](REPRODUCIBILITY.md)
